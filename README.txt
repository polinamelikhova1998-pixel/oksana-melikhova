ОКСАНА МЕЛИХОВА — EXECUTIVE PROFILE

Сайт готов для GitHub Pages. Загрузите содержимое папки (index.html и assets) в корень репозитория. В Settings → Pages выберите Deploy from a branch, main, /(root). Подождите публикации и откройте ссылку GitHub Pages.

Для изменения текста отредактируйте index.html.
Для замены главного фото: assets/portrait.jpg.
Для замены дополнительного фото: assets/portrait-secondary.jpg.
Для замены резюме: assets/resume.pdf.

Важно: на сайте опубликованы телефон и email из исходного резюме. Перед публикацией убедитесь, что владелица резюме согласна на публичное размещение контактов.
Шрифты загружаются из Google Fonts; при отсутствии сети используются системные шрифты.
